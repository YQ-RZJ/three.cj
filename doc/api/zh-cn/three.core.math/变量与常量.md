# 变量与常量
## let DEG2RAD
```cj
public let DEG2RAD: Float64 = PI / 180.0
```
度转弧度常量

## const LN2
```cj
public const LN2: Float64 = 0.6931471805599453
```
2的自然对数常量

## const PI
```cj
public const PI: Float64 = 3.14159265358979323846
```
圆周率常量

## let RAD2DEG
```cj
public let RAD2DEG: Float64 = 180.0 / PI
```
弧度转度常量
