# 类型别名
## type Access
```cj
public type Access = bgfx.Access
```
资源访问类型（Read / Write / ReadWrite）

## type AllocatorInterface
```cj
public type AllocatorInterface = Box < bgfx.AllocatorInterface >
```

```cj

public type Attachment = Box < bgfx.Attachment >
```
