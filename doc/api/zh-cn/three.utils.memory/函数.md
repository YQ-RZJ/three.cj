# 函数
## func intToCPointer\(T\)where T <: CType
```cj
public func intToCPointer < T >(int: T): CPointer < Unit > where T <: CType
```
将整数类型转换为指针

<p style="background:oklch(98% 0 0);color:black;border-radius:.375rem;padding:8px;margin:8px;white-space:pre-wrap;box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1);"><span style="text-shadow:2px 2px 4px rgba(0, 0, 0, 0.3);">💬 </span>内部通过 AutoFreePtr 临时分配内存并拷贝整数值，随后立即释放，
仅返回读取出的指针值本身。</p>

参数: 

|名称|类型|描述|
|---|---|---|
|int|T|整数数值（一般取自指针的整数表示）|

返回: 

- 转换得到的 CPointer<Unit>
